Customize Your QR Code

Every QR code has its own address, made of the text to encode, a style and a size. Put it in an image tag, or open it to download the image.

https://qrnegie.andrew.cmu.edu/qr.svg?text=https%3A%2F%2Fwww.cmu.edu%2F&style=mosaic&size=1024
OptionWhat It DoesDefault
text The URL or text to encode, up to 1024 bytes. URL-encode it, including any & or ? in the destination. It can also be a contact card (a vCard), which phones offer to save as a contact. None; required
style One of the styles below. scotty
size The image's width in pixels, up to 2048, and its height unless it has a header or footer. How small it can be depends on the style and how much text it holds. 512
header, footer A line of text above or below the QR code, up to 40 characters: letters, numbers, spaces and common punctuation. The image grows taller to hold it, except in Kraus Campo, where it goes in the orange band. None

Join options with &, in any order. If an option is misspelled or missing, the error message says what to change.

Beyond Links

A QR code can hold more than a link. The Builder's Content Type menu writes these for you; in an address, URL-encode the result as the text.

Content TypeWhat Phones DoStarts With
Contact Card Offer to save the contact. BEGIN:VCARD
Event Offer to add it to a calendar. BEGIN:VEVENT
Email Open a new email, with the address, subject and message filled in. mailto:
Phone Call Offer to call the number. tel:
Map Location Open the place in Google Maps. https://www.google.com/maps/
Wi-Fi Network Offer to join the network. WIFI:

The Builder's Wi-Fi codes are for CMU's wireless networks. Phones can't count on joining CMU-SECURE or eduroam from a code (iPhones can't join that kind of network from any QR code, and Android support varies), so codes for those two open Computing Services' steps for connecting instead. CMU-DEVICE is for registered devices without a browser, and CMU-GUEST asks guests to sign in with an access code from faculty or staff. Contact cards and events hold more text, so they make denser codes that read best at larger sizes.

Error correction lets a scanner read a QR code even when part of it is covered or smudged. The artistic styles use high error correction, so their artwork and marks can stand in for part of the code; Tilted Square, Block Monogram and Basic Black use medium, which keeps their codes less dense. The smallest module is in pixels.

Block Monogram's code is inverted, white on red, like the solid M of the monogram. Current phone cameras read inverted codes, but some older or simpler scanners don't; for a code that has to work everywhere, choose another style.

Sizes

A QR code is a grid of squares called modules, and each one gets the same whole number of pixels, at least the number in the table above. More text makes a bigger grid, so a long URL or a contact card needs a bigger image. If a size is too small, the error message gives the smallest one that works; the Builder picks it for you.

The size includes the white border around the code, and for Kraus Campo, its orange frame too. Start the artistic styles at 1024 pixels.

File Types

/qr.svg gives an SVG, which stays sharp at any size, for print layouts and web pages. /qr.png gives a PNG, for slides, email or a document that doesn't take SVG. Both take the same options.

Keep It Scannable

  • Keep the white border clear on all sides.
  • Keep the image square, without stretching or cropping it.
  • Use a shorter URL when a QR code gets too dense.
  • Scan the finished sign, slide or label with a phone, at its real size and distance.

MCP Server

AI agents can connect to QRnegie's MCP server at https://qrnegie.andrew.cmu.edu/mcp (Streamable HTTP, no sign-in). get_guide describes these options, and generate_qr takes text, style, size and an optional header and footer, and returns a PNG with its address and HTML. The setup prompt is on the home page.
